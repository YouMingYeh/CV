## Build the editable source

Install a TeX distribution (TeX Live or MacTeX), then run:

```sh
pdflatex -interaction=nonstopmode -halt-on-error CV.tex
pdflatex -interaction=nonstopmode -halt-on-error CV.tex
```

`CV.tex` is the editable source; `CV.pdf` is the current public document. Standard packages include Latin Modern, geometry, enumitem, titlesec, hyperref, and fancyhdr. Generated auxiliary files are ignored.

The PDF contains selectable text and clickable links. After editing, verify that it remains two pages and update the matching `public/CV.pdf` in the portfolio repository.
